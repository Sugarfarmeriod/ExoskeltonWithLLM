## Abstract
This study explores a large language model as a control interface for an upper-limb rehabilitation robot. High-level task execution based on an LLM is combined with low-level forward kinematics so users can issue intuitive commands for reaching, circular, and swinging rehabilitation movements. The reported experiments compare LLM-based and keypad-based controls using task success and usability measures.
