# 方法卡 04：试次反馈与重新规划

## 你只需要记住

- Inner Monologue 将成功检测、环境状态和人工反馈返回给 LLM。
- 随机执行失败时可以重试；原计划不可行时应重新规划。
- 没有成功检测时，Agent 可能误以为工具已经执行成功并继续错误流程。

## 在本项目中怎么用

将以下结果转成结构化反馈：

```text
trial_valid = false        -> 不优化，要求重新采集
safety_check = rejected    -> 返回拒绝原因，重新提案
metric_improved = false    -> 比较历史试次或调整方案
goal_changed = true        -> 重新选择工具和评价指标
```

## 证据

- PDF 第 2 页：重试、重新规划和请求人工反馈。
- PDF 第 4 页：Success Detection、场景描述和人工反馈分类。
- PDF 第 7 页：闭环反馈帮助系统从执行错误中恢复。

## 老师问时怎么说

“Agent 的闭环不发生在实时力矩层，而发生在试次层：工具返回试次是否有效、是否安全和是否改善，Agent 再决定重试还是换方案。”

## 不要说

- 不要把 LLM 的文字判断当成安全检测结果。
- 成功与否应优先由确定性指标工具判断。
