# 仍需确认的决策

这些项目不阻塞当前最小流程，但在接入真实外骨骼试次前需要用户、导师或工程负责人确认。

## 已确定的研究边界

- 导师当前规划招募 8 名健康受试者。这是预计样本量，不是已经完成的样本数。
- 人体实验定位为控制性能、可行性和个体化参数优化验证，不用于患者康复或临床疗效结论。
- 本论文和系统实现不采集、不使用 EMG 或 IMU。
- 可用信号范围以足底压力、AO 输出、膝角度、膝速度、参考轨迹和膝力矩为主。

## 人体实验协议

以下内容仍需在正式招募和采集前确认：

- 年龄范围、性别记录方式、身高/体重范围，以及明确的纳入与排除标准。
- 行走任务、速度/节拍、助力条件、参数条件、每条件重复次数和休息时间。
- 条件顺序的随机化或平衡方式，以及学习、疲劳和顺序效应的控制。
- 中止条件、紧急撤力流程、现场保护与不良事件记录。
- 8 人样本量的定位与依据；若不做正式功效检验，应明确为小样本可行性/重复测量工程研究。
- 主要结局、次要结局、统计检验、效应量、置信区间及多重比较处理。
- 伦理审批或豁免状态、知情同意、匿名化、访问权限和数据保存期限。

## 阈值

- 相位延迟阈值：当前默认 `0.05 s`。
- 峰值屈曲误差阈值：当前默认 `0.05`，单位需随真实角度单位确认。
- Tracking RMSE 阈值：当前默认 `0.08`，单位需随真实角度单位确认。
- 最少有效周期数：当前默认 `1`，真实行走试次建议提高。
- 力矩安全否决阈值：当前默认 `torque_limit_ratio >= 0.85` 时否决加大助力。
- 力矩强制减小阈值：当前默认 `torque_limit_ratio >= 0.95` 时建议轻微减小幅值/助力。

## 参考源

当前最小实现使用同一试次中导出的 `q_ref` / `dq_ref` 作为参考源。后续需要确认第一优先级：

- 健康侧。
- 健康人模板。
- 历史较优试次。
- 当前控制器参考轨迹。

## 参数映射

- `assist_gain` 当前是抽象建议标签，需要确认映射到真实模型中的哪个参数。
- `Amplitude`、`tau`、`phase_offset`、`MO_Kp`、`MO_Kd` 的允许范围和单步调整幅度需要由工程负责人确认。
- 参数建议必须保持人工确认，不得由脚本自动写入 Speedgoat 或 Simulink。

## 真实模型信号映射

真实工程模型导出的列名可能不是规范字段名。正式使用前，需要在 `metadata.json` 中补充 `signal_map`，将以下规范字段映射到实际列名：

- `q_meas`
- `dq_meas`
- `q_ref`
- `dq_ref`
- `feet_load`
- `phi`
- `phase0_event`
- `tau_e`
- `safe_torque`
- `assist_enabled`
