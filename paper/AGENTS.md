# 论文线 AGENTS.md

## 范围

论文线同时负责文献调研和论文写作。两者共享证据库，但应拆分为独立任务：调研任务交付可追溯的证据与判断，写作任务只使用已经核验的材料组织论证。

当前论文默认研究受约束 LLM Agent，不再把“LLM 是否必要”设为待实验回答的问题。可讨论为何采用 Agent 架构，但不安排无工具 LLM 或传统流程来证明 LLM 的存在合理性。

## 模型与任务类型

- 文献筛选、全文理解、公式/指标/算法等“工具资产”提取、证据审查、研究问题推敲和论文写作：`gpt-5.6-sol`，`medium`。
- 纯机械性的 PDF 批处理、格式转换或脚本维护可交给 `gpt-5.6-luna`，`max`；该任务不得独立作出学术结论。

任务名使用 `<派发者>-论文-<调研|精读|审查|写作>-<目的>`。

## 调研原则

每篇论文不只找作者明确命名的 tool，还必须检查方法、公式、指标、流程和判据是否可封装为本项目工具。尤其记录：输入、输出、公式/算法、适用条件、阈值来源、实验任务、失败条件和原文位置。

每项结论标注证据状态：`open_access_pdf`、`institution_access_pdf`、`manual_pdf`、`abstract_only` 或 `metadata_only`。只有全文证据才能支持公式、实现细节和精确实验设计判断。

全文处理采用分层漏斗：元数据/摘要 → evidence card → 定向页段 → 必要时精读全文。默认单轮最多精读 5 篇论文、处理 30 篇 evidence cards，并优先复用已有缓存。

每篇笔记至少包含题录、结论、Agent/AI 插入位置、控制底座、输入输出、目标函数或评价指标、实验对象与任务、项目映射、可借鉴点、不可照搬处和证据来源。

## 写作原则

- 研究主语是受约束、低频、人在环外骨骼 LLM Agent；确定性分析和安全工具是它的工具底座。
- 明确区分当前足底压力 AO 与既有 AFO 工作。
- 未完成实验前不得写结果性陈述；8 名健康受试者只能写作计划样本量。
- 不把 EMG、IMU、代谢仪或动作捕捉写成本项目输入或指标。
- 将模型提取内容视为候选证据；关键公式、数字、受试者信息和结论必须回到原文复核。
- 引言、相关工作、方法和实验协议可以并行起草；结果与讨论必须等待真实数据。

## 建议交付链

1. 文献调研：更新 paper matrix、evidence cards 与候选工具资产。
2. 证据审查：核验关键公式、指标、实验信息和引用。
3. 论证设计：形成 claim-evidence map 和章节合同。
4. 论文写作：按章节起草并保留待验证标记。
5. 独立审稿：检查事实边界、证据强度和过度宣称。
